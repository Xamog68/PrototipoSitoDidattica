# Prototipo del sito Didattica

Il repository contiene due copie navigabili della sezione Didattica:

- `attuale/`: fotografia dell'esistente, da conservare come riferimento;
- `proposta/`: laboratorio per la riorganizzazione di struttura e contenuti.

La pagina `index.html` consente di confrontare le due versioni tramite GitHub Pages.

## Regola di lavoro

Le modifiche progettuali vanno apportate soltanto in `proposta/`. La cartella `attuale/` viene aggiornata esclusivamente quando si decide di acquisire una nuova fotografia ufficiale del sito pubblico.
